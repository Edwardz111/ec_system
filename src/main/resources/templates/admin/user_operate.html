用户操作

对用户执行管理操作（取消 VIP、封禁账号等）

正常 封禁
超级管理员 SUPER_ADMIN 管理员 ADMIN 普通用户 无后台权限

管理员权限

设为管理员

授予后台登录权限（ADMIN），可管理用户、订单等

设为超级管理员

授予最高权限（SUPER_ADMIN），可设置/解除其他管理员

解除管理员

删除 admin 表记录，该用户将无法登录后台

VIP 与账号状态

设为 VIP

将该用户升级为 VIP 用户（is_vip = 1）

取消 VIP

将该用户降为普通用户（is_vip = 0）

封禁用户

将用户状态设为「封禁」，该用户将无法登录
